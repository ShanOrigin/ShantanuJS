blue comment for converting C language file into stand alone wave assembly and below mentioned all functions are exporting and initial memory size is 10 MB with O3 flag of optimization and math library linking

Command :

  emcc CMATH.c -O3 -lm \
  -s STANDALONE_WASM=1 \
  -s EXPORTED_FUNCTIONS='["_multiply3x3By1x3", "_multiply3x3By2x3", "_multiply3x3By3x3", "_multiply3x3By4x3", "_multiply3x3By5x3", "_multiply3x3Bynx3","_getData","_getTMatrix","_getStringBuf","_getSMatrix","_getTsMatrix","_getSSize","_getSHSize" , "_buildPath"]' \
  -s INITIAL_MEMORY=10485760 \
  -s ALLOW_MEMORY_GROWTH=1 \
  --no-entry \
  -o ../../build/WASM/CMATH.wasm
